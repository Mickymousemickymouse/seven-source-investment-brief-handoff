## 一、固定来源与用途

## 二、纳入标准：只保留边际变化

1. 每条信息拆分为 `fact`（可核实事实、事件、数据变化）和 `take`（来源的观点、判断、预测）。
2. 段子、情绪表达、简短点评，如果没有新的 `fact`，仅重申或强化既有 `take`，不纳入信息提炼或策略观点。
3. 以下内容可以纳入：
   - 包含事件或数据变化的短评；
   - 提供新逻辑、新证据、反证、观点修正或新测算的深度内容/长文；
   - 对上一期结论产生实质影响的最新观点。
4. 不用旧内容填充栏目。没有边际变化的栏目可以为空或跳过。
5. 同一主题先去重再判断热度。热度按提及该主题的不同“信息提炼”来源数量排序；同一来源的重复转发不重复计数，重复转载也不构成交叉验证。
6. 每个主题先写新增 `fact`，再写相关 `take`，保留来源、原始北京时间和原文链接。无法核实的内容保持为来源说法。

## 三、优先级

1. 持仓股或持仓相关板块的边际变化。
2. 用户明确提供的关注池内股票或板块的边际变化。当前未提供关注池时注明“关注池名单待提供”，不得猜测。
3. 被不同“信息提炼”来源提及最多的主题。高关注不等于事实已证实。
4. 其余内容按影响范围、变化幅度、证据质量和时效性排序。

## 五、报告正文：固定四类信息

### 固定版式（2026-09-30 修订）

- 以 reports/2026-09-29-0830.md 的重新排版晨报为版式参照，不复制其中旧新闻、旧数字及已废止的 Fact/Take 标签。
- 顺序固定为：运行元数据 → 本期最重要的5条 → 一、市场复盘 → 二、信息提炼 → 三、重大提示 → 四、阅读提示 → 五、最终总结 → 完整7源覆盖表 → 待补读/待核实清单。
- “本期最重要的5条”必须保留：编号、加粗核心变化、简短解释影响与验证点，附来源。不足5条如实减少，不能填充旧闻；正文展开时避免重复整段。
- 信息提炼各板块使用编号、加粗主题标题与精炼连贯段落，保持读与听都能串起逻辑。
- 后续修改优先于旧样式：策略并入市场复盘，禁用 Fact/Take 固定标签，保留现有语音过滤、英文原词和自然衔接规则。

### 0. 阅读与口播共用的叙事规则

- 最终报告既是阅读稿，也是唯一的口播底稿。排版整齐之外，必须保证只听音频也能还原逻辑。
- 大章节如需引导，只保留有实质信息的1–2句，不加编号；没有必要则直接进入细分内容，不强制写开场。具体信息条目继续编号，按“发生了什么 → 为什么 → 影响什么 → 接下来验证什么”推进，同一因果链写在一起。
- 删除“本期能读到的增量主要集中在……”“以下按主题合并……”等泛泛的编写说明，不在正文反复解释采集、去重与核实方法。必要的具体来源限制放在对应条目或覆盖附录，事实与观点的边界仍须保留。
- `fact`、来源观点和推导必须保持边界，但不机械堆叠“Fact/Take”标签。优先写成连贯完整句，例如“先看事实……这意味着……但仍需验证……”。
- 正文不得使用“Fact：”“Take：”作为固定前缀。每个主题改写为自然的因果段落：先交代可确认变化，再说明来源观点或推导，最后给出影响与验证点；口播应能仅凭上下文听清哪部分是事实、哪部分是判断。
- 大章节之间仅在有助理解时保留有信息量的承接，不加编号；不为衔接而重复前文，不用“接下来我们来看”等空泛套话。
- 小标题只用于真正切换主题；同一主题内部优先使用短段落。连续罗列数据时，最后必须补一句把数据串成结论。
- 口播停顿以完整语义段为单位，不在每个项目符号后机械长停。表格只放覆盖审计等附录，正文尽量不用表格承载核心逻辑。

### 1. 市场复盘

- 汇总计划窗口内 A 股、日韩市场、美股的显著变化并简要说明原因。
- 每个市场先写可确认的涨跌、幅度和结构，再分析可能原因；不得一上来只讲原因而不交代市场表现。
- 指数行情只写涨跌百分比，例如“标普500跌0.2%，道指跌0.3%”，不再写“至XXXX点”。收益率、政策金额、产业测算等有实质意义的数字保留。
- 美股盘前或盘后仅在出现明显涨跌或重要定价变化时纳入。
- 行情数据和原因可使用交易所、指数提供方、公司公告及可靠市场数据等可核实来源；这些辅助来源不计入 7 个指定内容源的覆盖表或热度统计。
- 价格、涨跌幅和原因必须有依据；原因不确定时明确写“市场解释”或“来源观点”。
- 不机械罗列指数涨跌。交代行情后，提炼本窗口最有解释力的主线，再说明“事件/数据 → 利率、汇率、商品或风险偏好 → 资产表现”的可能传导链。
- 区分可确认催化、市场普遍解释和仅有时间相关性的现象；证据不足时明确写“无法确认单一原因”，不得为了完整叙事强行归因。
- 优先解释指数内部结构、跨资产印证和反常表现（例如避险事件中黄金反而下跌），并指出后续可验证变量。
- 原“策略观点”并入市场复盘末尾的“综合判断与验证点”，基于本期行情、信息提炼和重大提示，区分事实、来源观点与推导，并简要列出反证、风险和下一验证点；不给买卖指令或确定性预测。
- 市场复盘保持高信息密度：先行情、后原因、再判断；避免同一因果链在不同小节重复展开。
- 市场复盘的推荐顺序固定为：全球与主要市场涨跌 → 跨资产共同信号 → 主因果链 → A股/日韩与持仓的差异化影响 → 综合判断和验证点。开头必须先让听众知道“什么涨、什么跌”，随后再解释。

### 1.1 完整报告语音版

- 每份报告同时生成从第一个实质内容章节开始、到“完整7源覆盖表”标题之前结束的中文语音文件，不再只播“本期最重要的5条”。
- 语音不朗读报告标题之前或正文之前的运行元数据，包括计划时点、覆盖区间、实际生成时间、音频链接、覆盖状态和同步说明。晨报统一以“早上好，下面是今天的隔夜市场信息播报”简短开场；晚报统一以“晚上好，下面是今天的晚报内容播报”开场，随后立即进入第一个实质内容章节。
- 除上述开场和元数据过滤外，直接以最终报告正文生成语音，不另写、改写或压缩口播稿。可机械跳过网址、Markdown标记和表格分隔线，但不得改变或遗漏口播范围内的实质文字。遇到“完整7源覆盖表”标题时立即结束口播：该覆盖表、表后说明、“待补读/待核实清单”及其后全部内容均不进入语音。
- 文字报告继续保留来源、原始时间和链接，但语音中不朗读正文内仅用于溯源的内容：包括独立成行或句内的“来源：×××”、来源名称、发布时间、方括号溯源引用和网址，例如“来源：⭕短评&信息，2026-09-28 23:08”或“[⭕短评&信息，2026-09-28 23:08]”。若整行仅为来源则整行跳过；若来源附在实质句子末尾，只删除溯源部分，保留实质内容并保证句子自然收尾。不额外补写口播稿。
- 来源排版采用段末同行全角括号，例如“正文。（来源：名称，原始北京时间，[原文链接](URL)）”，不另起来源行。口播机械删除整个来源括号，保留前面的实质正文；旧版独立来源行也继续过滤。
- 声线和节奏以接近真人的中文新闻播报为目标：使用短句、自然转折、段落级停顿和重点词轻重变化，避免机械念序号、密集数字和报告腔；数字改写成适合口语收听的表达。
- 开头使用一句简短、正式的时段问候和栏目提示，例如“早上好，下面是隔夜市场信息播报”，随后立即进入第一条实质信息；不使用“先不用记太多数字”“真正值得关注的是”“下面讲五条”等卖关子或冗余铺垫。语气采用稳健、清晰的专业新闻播报风格，但不模仿具体主持人的个人声线；停顿自然舒适，语速接近正常财经新闻，避免慢速朗诵腔。
- 默认采用年轻、柔和但保持专业感的成年女声新闻播报音色。以标点和语义自然换气为主，只在主题切换处短停，避免逐句人为停顿。英文缩写、公司名和专业词保留原英文，不改写成中文名称。
- 在任务回复中同时提供可播放的完整报告音频和完整报告链接。
