# 交接包的分享范围与安全边界

本包供接手同事在其 MacBook 的 Codex 环境中阅读、继续开发和实机验收七源投资晨晚报。用户于 2026-10-18 明确选择将**现有完整交接包原样公开**到 GitHub，因此任何人都可查看、下载和复制包内文件。它交付**当前找回并重建的代码与工作说明**，不交付原机的登录状态、会员资料原件或可直接运行的私人业务配置。接收方须在自己的设备上配置目录、登录七源，并重新完成真实验收；复制本包本身不证明定时采集已经通过。

**业务敏感性提醒：**当前代码与需求文字本身包含固定星球 ID、X 账号和八个持仓证券代码，以及用户沟通摘要和旧运维规则。原机 `holdings.json` 等私有配置文件未打包。本包并非匿名源码；公开后即使将仓库改回私有，也无法收回他人已经下载的副本。

## 外发前检查

1. 逐项核对归档文件列表，确保只有上表“包内包含”的白名单内容，没有原始采集、历史成品、缓存、私有配置或符号链接指向包外文件。
2. 搜索包内文本中的明文凭据、认证头、Cookie、签名 URL 查询、邮箱、个人姓名、本机绝对路径和私人持仓；对命中项人工复核并脱敏。配置模板不得保留可用的真实值。
3. 检查压缩包是否能在独立目录解压，文件哈希与清单一致，源码可读、测试能启动；记录未通过项，不把测试通过写成 Mac Scheduled 或 Windows 实机验收通过。
4. 发送给指定同事后，由其在本机设置业务路径、授权来源与持仓名单，并使用自己的已登录浏览器完成七源、评论、附件、公告、报告及音频的真实验收。不得复制原机认证文件或修改安全设置来绕过访问限制。

本次只读审计未在当前文本中检出明显的明文私钥、`Authorization`／`Cookie` 头或常见 Token／密码赋值，但**这不等于保证零泄露**。自动关键词扫描不能识别所有编码形式、图片中的信息、嵌入文件或业务敏感内容；归档完成后仍须按上述清单人工复核。
