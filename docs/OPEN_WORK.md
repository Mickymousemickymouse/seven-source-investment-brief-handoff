# 待改事项与完成标准

按当前用户要求继续开发时，同事先在 **MacBook** 接手，**优先保证来源和阅读事实，再优化交付速度**。Windows 原需求不取消，但实机测试暂缓；下列关键项完成前，不得称“Mac 端完整自动交付已验收”，更不得称“双平台完整程序已验收”。所有缺口按期次、来源和失败阶段记录；旧报告、旧设备测试或模拟数据不能顶替本期事实。

| P0 | 七源真实采集贯通 | 在用户授权的浏览器会话中，四个指定星球及三个 X 账号分别遍历到时间窗口边界；保存原生主题/帖子身份、原始事件时间、观察时间、来源链接。Python 当前只导入快照，需新增经授权、稳定的实际读取衔接。浏览器失败明确记在发现、会话、标签页、页面或附件哪一层，不用列表数量宣称读全 |
