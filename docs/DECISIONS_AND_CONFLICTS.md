## 当前平台与部署决策

- **本次接手优先 macOS**：同事使用 MacBook。业务路径按其本机明确配置；原机 `mac_audio_config.json` 指向原用户的本机 `Music/InvestmentBrief` 目录，原因是原 Mac 的项目 Documents 目录可能被 iCloud 卸载为占位文件。该原机绝对路径不能直接当同事机器路径。原 Mac 的手动诊断/部分手动报告不等于同事 Mac 的 Scheduled 端到端通过。
- **Windows 后续保留、实机验收暂缓**：业务根默认 `D:\InvestmentBrief\project`，配置 `D:\InvestmentBrief\paths.json` 位于 project 上一级，音频部署原设 `D:\DigestAudio`；不回退 C 盘，不覆盖现有旧项目。原交接的 PowerShell/Job Object/System.Speech/Yaoyao/ACL/哈希和固定许可是历史实现合同，现恢复包未包含后续完整 Windows 业务源码。待用户重新安排 Windows 阶段时再合法安装并实机验证；不能复制旧主机许可或任务 ID，也不能把暂缓写成通过。
- **身份与数据**：用户只授权使用现有合法登录和支持的浏览器能力。不得上传 Cookie、Token、密码、私有认证配置，不复制会员原文到第三方 API，不更改系统安全设置、VPN 模式、扩展策略或用非支持底层连接绕过浏览器安全终止。
- **程序状态**：原 `outputs/investment-brief` 曾被误删，现存程序是部分重建。历史交接材料提供规则/配置，不提供已迭代的完整源码。`digest/browser_bridge.py` 与 `collect_browser_snapshot.py` 接收当轮真正捕获的快照，但不会自行操控 Chrome；八证券公告自动接线、完整 Scheduled 采集阅读交付链、Windows 并排部署及实机验收仍待做。
