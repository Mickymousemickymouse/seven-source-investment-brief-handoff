# 当前定时合同与迁移边界

本机当前 Codex 心跳任务名为“七源投资晨晚报（08:00／20:00预处理，09:00／21:00交付）”，截至本次打包检查为 `ACTIVE`。该任务绑定**原聊天与原机环境**，不随代码压缩包转移；也没有可从本包独立运行的后台七源采集服务。设置已启用不等于某期 Scheduled 成功。

| 北京时间 | 任务 | 时间范围 | 必做检查 |
| --- | --- | --- | --- |
| 08:00 | 晨报预处理 | 前日21:00 至当日08:00已发生部分 | 七源列表/正文/可见评论/附件、行情、东方财富八证券公告、原始事件时间及审读证据；仅保存草稿和检查点 |
| 09:00 | 晨报交付 | 前日21:00（含）至当日09:00（不含） | 补最后一小时，重查旧主题新评论/附件与 X、行情、公告，校验整窗覆盖，再定稿、生成完整离线音频并核验交付 |
| 20:00 | 晚报预处理 | 当日09:00 至20:00已发生部分 | 与晨报预处理相同；不得提前推送 |
| 21:00 | 晚报交付 | 当日09:00（含）至21:00（不含） | 与晨报最终交付相同 |

同一报告窗口的真实有效证据可续用；失效、修改或时间不符的证据逐项重读。跨窗口旧快照、旧报告、源列表计数和下载完成均不能代替本期正文/评论/附件审读。来源或音频出错时记录准确阶段和已完成部分，不把手动延时补报标成 Scheduled 成功。报告与音频交付核验通过后，才按用户授权精确清理本轮已完成下载与音频临时文件。

接手同事使用 MacBook。其 Codex 要先在本机建立合法浏览器访问、Mac 音频目录和真实 Scheduled 测试，再自行创建适配其聊天的定时任务；不得复制本机任务 ID、线程标识、登录状态或原机安全许可。Windows 时间/路径/Yaoyao 要求保留在需求文档，但 Windows 实机测试按用户最新指令延后。
